# 蒸着品質分析システム

CSVデータ（例: `SO24G-L14 R2_20260529.csv`）をフォルダ単位で読み込み、
波形確認・標準値比較・日付トレンド監視を行う Streamlit アプリです。

## 主な機能
- フォルダ選択（入力またはダイアログ）でCSVを一括読込
- ファイル名から「機種名」「測定位置」「日付」を自動抽出
- B～U列（測定データ）を2D波形として表示
- 重要測定点の標準値を手入力し、標準波形（補間）を重ね表示
- 規格逸脱率（許容差超過）を算出し、アラート一覧表示
- 日付ごとの品質トレンド（逸脱率推移）を表示

## 起動方法

### 方法1: 起動スクリプトを使用（推奨 / ネットワークアクセス対応）

**Windows 環境:**
- `run_server.bat` をダブルクリック
- または `run_server.ps1` を PowerShell で実行

**Linux/Mac 環境:**
```bash
chmod +x run_server.sh
./run_server.sh
```

起動後、ターミナルに表示される URL からアクセスしてください：
- **ローカルアクセス**: http://localhost:8501
- **ネットワークアクセス**: http://（ホストのIPアドレス）:8501

### 方法2: コマンドラインから直接実行

1. 依存関係をインストール
   ```bash
   pip install -r requirements.txt
   ```
2. アプリ起動
   ```bash
   streamlit run app.py
   ```
   または
   ```bash
   python app.py
   ```

### ネットワークアクセスについて

- 起動スクリプトで `0.0.0.0` にバインドされるため、ローカルネットワーク内の他のマシンから IP アドレスでアクセス可能
- インターネット経由でアクセスする場合は、ファイアウォール設定やルーターのポート転送を設定してください
- セキュリティが重要な場合は、リバースプロキシ（Nginx など）の導入を検討してください

## ファイル名ルール
- 想定形式: `機種名 測定位置_YYYYMMDD.csv`
- 例: `SO24G-L14 R2_20260529.csv`

## データ形式
- A列: 測定点（例: 波長）
- B～U列: 測定データ（複数系列）
- 先頭に装置情報行があっても、自動でヘッダー行を検出します。
